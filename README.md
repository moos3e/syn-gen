# Syn-gen

A minimalist, dark-themed synonym finder built with React and TypeScript. Get instant synonyms for any word with a beautiful, modern interface.

## Features

- 🌙 Dark mode interface
- ⚡ Instant synonym lookup
- 📊 Relevancy scoring
- 🎯 Minimalist design
- 🔄 Real-time results

## Tech Stack

- React 18
- TypeScript
- Chakra UI
- Vite
- Datamuse API

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/moos3e/syn-gen.git
cd syn-gen
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Building for Production

```bash
npm run build
```
